# Calculadora

Calculadora simple hecha con HTML, CSS y JavaScript puro. No necesita instalar nada.

## Cómo usarla

Abre `index.html` en tu navegador. También funciona con el teclado (números, `+ - * /`, `Enter`, `Backspace`, `Esc`).

## Estructura

- `index.html`: los botones y la pantalla
- `style.css`: colores y estilos (los colores están al inicio, en `:root`)
- `script.js`: la lógica de la calculadora
